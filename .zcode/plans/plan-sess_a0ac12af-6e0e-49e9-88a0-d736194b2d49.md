# 找回密码功能实现方案

## 一、概述

克隆"注册三步流程"，做语义翻转，新增 `POST /auth/password/{send-code, verify, reset}` 三个公开端点。重置成功后调用 `stputil.Kickout(userID)` 踢下线该用户所有设备的会话，不自动登录。

### 流程
```
用户输入邮箱
  → POST /auth/password/send-code  （邮箱必须存在 → 发验证码邮件）
  → POST /auth/password/verify     （校验验证码 → 标记 pwd_reset:verified）
  → POST /auth/password/reset      （校验已验证 → 改密码 → Kickout 所有会话）
  → 用户用新密码走 POST /auth/login
```

## 二、决策汇总（已全部确定）

| 决策 | 方案 |
|---|---|
| 路由 | 公开组 `/auth/password/{send-code,verify,reset}` |
| Redis key | 独立前缀 `pwd_reset:code:` / `pwd_reset:verified:` / `pwd_reset:rate:` |
| domain 接口 | 新建 `PasswordResetStore`（与 `VerificationStore` 同构，独立接口单一职责） |
| 邮箱不存在 | 404 + 新增 `errAccountNotFound` |
| 重置后 | 不自动登录 + `Kickout(userID)` 踢所有设备 |
| 邮件模板变量 | `{{.Email}}` + `{{.Code}}` |
| 邮件发送 | `EmailSender` 接口加 `SendPasswordResetCode` 方法 |
| 密码校验 | 用 `password.MinLength`（=6）常量 |
| 账号状态 | 仅 `Status == UserStatusActive` 可重置 |
| 邮件模板风格 | 复用注册模板深色 GitHub 风格（`#0d1117`/`#2dd4bf`），仅改文案 |

## 四、关键技术细节

### 4.1 kickout 为什么用独立接口方法而非复用 Logout
`Logout(loginID, device)` 是按设备登出，需要传 device 参数。找回密码场景需要踢所有设备，`stputil.Kickout(loginID)`（variadic 不传 device）才是"踢全部"。语义不同，故新增 `Kickout(loginID string)` 方法。

### 4.2 为什么不复用 register:* Redis key
同一邮箱可能并发发起"注册"和"找回密码"（如先点注册→又点找回）。若复用 key，两套流程的验证码/verified 标记会互相覆盖。独立前缀 `pwd_reset:*` 彻底隔离。

### 4.3 ResetPassword 校验链顺序
1. `password.MinLength` 长度校验（快速失败，不查 DB）
2. `IsVerified` 校验（防跳步）
3. `GetByEmail`（确认账号仍存在）
4. `Status == Active`（不给被禁用户重置）
5. `password.Hash` → `UpdatePassword`
6. `Kickout`（失败仅 Warn，不阻断——密码已改，旧 token 即使残留也因密码变了而风险可控；实际上 sa-token 的 token 校验不查密码，所以 kickout 失败会让旧会话残留，故 kickout 错误应记录但尽量不阻断。按 best-effort 处理与 Login 的 hash upgrade 失败处理一致）

### 4.4 邮件模板发送的架构改动
当前 `SendWithTemplate` 硬编码读 `c.verificationTemplates[lang]`。重构为：
```go
// 私有通用方法
func (c *Client) sendTemplate(ctx, toEmail, lang, templateUUID string, variables map[string]interface{}) error
func (c *Client) SendVerificationCode(ctx, toEmail, code, lang string) error {
    uuid := c.verificationTemplates[lang]
    return c.sendTemplate(ctx, toEmail, lang, uuid, {"Email": toEmail, "Code": code})
}
func (c *Client) SendPasswordResetCode(ctx, toEmail, code, lang string) error {
    uuid := c.passwordResetTemplates[lang]
    return c.sendTemplate(ctx, toEmail, lang, uuid, {"Email": toEmail, "Code": code})
}
```
